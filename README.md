# StudyBuddy – Online Tutor Platform

## 📚 Project Overview

**StudyBuddy** is an online tutor platform designed to provide a modern and user-friendly interface for online learning and tutoring. The project uses React and Vite to create a fast, responsive web application with clean typography and a foundation for an engaging educational experience.

## ✨ Features

- **Modern UI:** Clean interface designed for an online tutoring platform.
- **React-Based Frontend:** Component-based architecture for building reusable UI elements.
- **Fast Development:** Powered by Vite for a quick development server and efficient builds.
- **Typography:** Uses DM Sans, Inter, and Sora fonts from Google Fonts.
- **Responsive Foundation:** Includes viewport configuration for mobile and desktop screens.
- **Custom Branding:** Includes an HTML page title and favicon configuration.

*Note: Additional platform features depend on the React components and application code implemented in the project.*

## 🛠️ Technologies Used

- **React** – User interface development
- **Vite** – Development server and build tool
- **HTML5** – Application entry page
- **CSS3** – Styling and layout
- **JavaScript (ES6+)** – Application logic
- **Google Fonts** – DM Sans, Inter, and Sora

## 🚀 Getting Started

### Prerequisites

Install the following software:

- [Node.js](https://nodejs.org/) (LTS version recommended)
- npm, included with Node.js
- A code editor such as Visual Studio Code

### Installation

1. Clone the repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Open the project folder:

   ```bash
   cd StudyBuddy
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL shown in your terminal, usually:

   ```text
   http://localhost:5173
   ```

## 🏗️ Build for Production

To create an optimized production build, run:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```
